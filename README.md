# Spring Boot Demo Application

This is a simple Spring Boot 3.2.5 application.

## Upgrade Notes

This application has been upgraded from Spring Boot 3.1.5 to 3.2.5. Key changes include:
- Updated `spring-boot-starter-parent` version in `pom.xml`.
- Removed deprecated `spring.mvc.pathmatch.matching-strategy` property from `application.properties`.

## How to run

```bash
mvn spring-boot:run
```

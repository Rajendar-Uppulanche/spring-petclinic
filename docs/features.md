# Application Features

This document outlines the key features available in our application.

## Pet Management

### NFR-066: Comprehensive Preventive Care Record Keeping for Pets
The system now offers robust capabilities for managing preventive care records for pets. This includes:
- Recording vaccinations, deworming, and other routine treatments.
- Tracking due dates for upcoming preventive care.
- Generating reports on a pet's preventive care history.
- Integration with pet profiles for a holistic view of pet health.

## Owner Management

### NFR-067: Enhanced Owner Record Search and Review
Clinic staff can now efficiently locate and review owner records with enhanced search functionalities. Key improvements include:
- Advanced search filters by name, contact information, and associated pets.
- Quick access to owner details, including contact information, pet ownership, and visit history.
- Improved UI for displaying owner records, making information more accessible and readable.

## Other Features
- Basic pet profile management.
- Appointment scheduling.

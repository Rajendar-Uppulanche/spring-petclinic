# User Manual

## Managing Veterinarians

### Viewing the Veterinarians List

To view a list of all registered veterinarians, navigate to the "Veterinarians" section from the main menu.

### Filtering Veterinarians by Specialty

The veterinarians list page now includes a filter dropdown to help you quickly find veterinarians with specific specialties.

1.  **Locate the Filter:** Above the list of veterinarians, you will find a dropdown labeled "Filter by Specialty:".
2.  **Select a Specialty:** Click on the dropdown and choose a specialty from the list (e.g., "Radiology", "Surgery", "Dentistry").
3.  **View Filtered Results:** The list of veterinarians will automatically update to show only those who possess the selected specialty.
4.  **View All Veterinarians:** To remove the filter and see all veterinarians again, select the "All Specialties" option from the dropdown.

**Messages:**
*   If no veterinarians are found for the selected specialty, a message "No veterinarians found for the selected specialty." will be displayed.
*   If there are no specialties available in the system (i.e., no vets have any specialties), the filter dropdown will be disabled, and a message "No specialties available for filtering." will be shown.

### Non-Functional Requirements (NFR) Compliance

**NFR-003: Usability**
The specialty filter dropdown on the veterinarians list page has been designed with usability in mind:
*   **Intuitive Placement:** The filter is clearly visible and positioned logically above the list it affects.
*   **Clear Labeling:** The dropdown is clearly labeled "Filter by Specialty:" to indicate its purpose.
*   **"All Specialties" Option:** A default "All Specialties" option is provided to easily reset the filter.
*   **Dynamic Updates:** The list updates dynamically without a full page reload, providing immediate feedback to the user.
*   **Informative Messages:** Clear messages are displayed when no veterinarians match the filter or when no specialties are available, guiding the user.
